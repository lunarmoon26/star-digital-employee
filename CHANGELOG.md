# Changelog

All notable changes to Star Digital Employee are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Product contract, target architecture, implementation roadmap, and initial
  architecture decision records for the digital employee platform.
- Versioned `Employee` recipe contract and validation CLI foundation.

### Changed
- Repositioned the project from a Claude Code plugin marketplace to an
  infrastructure-as-code digital employee platform powered by DeepSeek Harness.
- Classified the existing Claude plugin collection as migration input rather than
  the runtime architecture.

## [0.1.0] - 2025-01-22

### Added
- Initial marketplace structure
- Sample plugin with `/hello` command
- Plugin ideas document with 30+ concepts
- Marketplace catalog (.claude-plugin/marketplace.json)
- Documentation for plugin development
- Support for internal and external plugins
- Categories for development, knowledge, learning, and growth

### Documentation
- README with mission and overview
- PLUGIN_IDEAS.md with comprehensive plugin concepts
- CONTRIBUTING.md with versioning guidelines
- Individual README files for plugins/ and external_plugins/
